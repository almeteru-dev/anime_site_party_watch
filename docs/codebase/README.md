# Codebase Documentation / Документация кодовой базы

## English
This folder contains bilingual documentation for the project source code.

**Important scope note**
- The goal is to document the *project source* (backend + frontend).
- Generated and third‑party code is excluded from deep documentation (e.g. `backend/ent/**`, `frontend/node_modules/**`, `frontend/.next/**`).

**Files**
- `reference.en.md`: auto-generated file index + symbol list (functions/components)
- `reference.ru.md`: the same, Russian

## Русский
Эта папка содержит двуязычную документацию по исходному коду проекта.

**Важно про охват**
- Цель — описать *исходники проекта* (backend + frontend).
- Сгенерированный и сторонний код не документируется подробно (например `backend/ent/**`, `frontend/node_modules/**`, `frontend/.next/**`).

**Файлы**
- `reference.en.md`: авто‑сгенерированный индекс файлов и список символов (функции/компоненты)
- `reference.ru.md`: то же на русском
