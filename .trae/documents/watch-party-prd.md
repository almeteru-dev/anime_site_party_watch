# Продуктовые требования к функционалу "Совместного просмотра" (Watch Party) для LycorisLib

## 1. Обзор продукта
Функционал позволяет пользователям создавать приватные комнаты для совместного просмотра аниме через Kodik плеер, обеспечивая полную синхронизацию воспроизведения для всех участников. Решает проблему организации совместного просмотра для небольшой группы людей без публичных списков комнат.
Комнаты автоматически удаляются через 12 часов после создания, что позволяет эффективно использовать ресурсы сервиса.

## 2. Основные функции

### 2.1 Роли пользователей
| Роль | Метод получения | Основные права |
|------|-----------------|----------------|
| Владелец (Owner) | Назначается при создании комнаты | Управление плеером (play/pause/seek), выбор серии/озвучки, передача прав владения другому участнику |
| Зритель (Viewer) | Присоединение по уникальной ссылке | Только просмотр видео, синхронизация состояния плеера с Владельцем |

### 2.2 Модули страниц
Функционал Watch Party состоит из следующих основных страниц:
1. **Страница комнаты просмотра**: Kodik плеер, список участников комнаты, интерфейс управления (только для владельца), чат участников (опционально).

### 2.3 Детали страниц
| Название страницы | Модуль | Описание функций |
|-------------------|--------|-----------------|
| Страница комнаты просмотра | Код доступа | Ограничивает доступ к комнате только по уникальной ссылке /watch-party/[roomId], запрещает индексацию поисковыми роботами |
| | Автоматическое удаление комнаты | Уничтожает данные комнаты через 12 часов с момента создания, используя серверный механизм очистки |
| | Ролевая модель | Присваивает роль Владельца создателю комнаты, остальным участникам - роль Зрителя |
| | Передача прав владения | Позволяет текущему Владельцу передать свои права любому другому участнику комнаты через интерфейс |
| | Интерфейс выбора серий/озвучек | Отображает для Владельца переиспользованный из каталога интерфейс выбора серий и озвучек; скрывает/блокирует его для Зрителей |
| | Синхронизация плеера | Передает команды управления плеером от Владельца всем Зрителям через WebSockets, обеспечивая синхронное воспроизведение |
| | Kodik плеер | Встраивает плеер, обрабатывает события от Kodik API и отправляет команды управления в соответствии с ролью пользователя |

## 3. Основной процесс работы
```mermaid
graph TD
    A[Пользователь создает комнату] --> B[Генерация уникального roomId]
    B --> C[Установка таймера уничтожения комнаты (12ч)]
    C --> D[Создатель становится Владельцем]
    D --> E[Владелец делится ссылкой /watch-party/[roomId]]
    E --> F[Зрители переходят по ссылке и присоединяются к комнате]
    F --> G[Владелец управляет плеером]
    G --> H[Сервер рассылает команды всем Зрителям]
    I[Владелец передает права другому участнику] --> J[Новый пользователь получает права Владельца]
    K[Таймер истекает] --> L[Комната автоматически удаляется]
```

## 4. Дизайн пользовательского интерфейса
### 4.1 Стиль дизайна
- Основные цвета: Темная тема (как в основном проекте LycorisLib), акцентный фиолетовый #8b5cf6 для кнопок управления
- Кнопки: Скругленные (border-radius 8px), с эффектом наведения, размеры адаптивные
- Шрифты: Inter, размер основного текста 16px, заголовков 24px
- Лейаут: Карточная компоновка, плеер занимает основную часть экрана, справа/снизу панель с участниками
- Иконки: Минималистичные svg-иконки для управления плеером, корона для обозначения Владельца

### 4.2 Обзор дизайна страниц
| Название страницы | Модуль | Элементы UI |
|-------------------|--------|-------------|
| Страница комнаты | Основной лейаут | Флекс-лейаут: плеер (70% ширины) + панель участников (30% ширины) на десктопе |
| | Список участников | Карточки с никнеймами, иконка короны у текущего Владельца, кнопка "Передать права" только для текущего владельца |
| | Панель управления плеером | Для Владельца: кнопки play/pause, ползунок перемотки, селекторы серий и озвучек; для Зрителей: только отображаемое время воспроизведения |
| | Kodik плеер | Стандартный размер 1280x720, fullscreen поддерживается, работает с API Kodik для приема и отправки событий |

### 4.3 Адаптивность
Десктоп-first, адаптив для мобильных устройств: на разрешениях <768px панель участников перемещается под плеер, интерфейс управления масштабируется под сенсорные экраны.

### 4.4 Технические особенности реализации интерфейса
- Обработчик сообщений от Kodik плеера находится в useEffect с пустым массивом зависимостей и функцией очистки removeEventListener
- Экземпляр WebSocket, ссылка на iframe плеера и текущее состояние (серия, озвучка) хранятся в useRef для предотвращения лишних ререндеров
- Перед обновлением состояния плеера добавлены проверки на совпадение текущих значений, чтобы избежать повторных отправок команд
