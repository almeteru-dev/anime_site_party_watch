# Дизайн страниц: кликабельные жанры/темы/рейтинг → подборка

## Глобальные правила (для новых/обновляемых блоков)
- Подход: desktop-first, затем адаптация под tablet/mobile.
- Layout: гибрид CSS Grid + Flexbox.
  - Основной контент (листинг) + правая колонка фильтров: Grid (2 колонки).
  - Чипы/кнопки/внутренние ряды: Flexbox.
- Responsive:
  - Desktop (>=1024px): 2 колонки (контент + right filters).
  - Tablet (768–1023px): 2 колонки с уменьшенной правой колонкой.
  - Mobile (<768px): правая колонка уходит ниже листинга или в выезжающую панель, но логика фильтров «как в каталоге» сохраняется.
- Типографика:
  - Заголовок страницы: 28–32px, semibold.
  - Подзаголовок (EN): 16–18px, normal/medium, приглушённый цвет.
  - Описание: 14–16px, ограничение ширины строки.
- Интеракции:
  - Чипы кликабельных жанров/тем/рейтинга: hover (подсветка/underline), active (нажатие), focus-visible (контур).
  - Предвыбранный фильтр на странице подборки визуально отмечен как выбранный (состояние selected).

## 1) Страница аниме (обновление существующей)

### Meta Information
- Title: «{Название аниме (RU)} / {Название (EN)}»
- Description: краткое описание/аннотация аниме (если уже есть на странице)
- Open Graph: og:title, og:description, og:image (постер)

### Page Structure
Типовой профиль/детальная страница: шапка с постером и метаданными, ниже — вкладки/секции.

### Sections & Components
1. Блок метаданных (существующий)
   - **Чипы жанров**: каждый жанр отображается как chip/button.
     - On click: переход на страницу подборки с предвыбором `kind=genre`.
   - **Чипы тем**: аналогично жанрам.
     - On click: переход на страницу подборки с предвыбором `kind=theme`.
   - **Рейтинг** (например, значок/лейбл): становится кликабельным элементом.
     - On click: переход на страницу подборки с предвыбором `kind=rating`.
2. Состояния
   - Loading: skeleton для метаданных.
   - Disabled: если для атрибута нет значения (например, рейтинг отсутствует) — элемент не показывать.

## 2) Страница подборки (новая)

### Meta Information
- Title:
  - Если kind=genre: «Жанр: {RU} / {EN}»
  - Если kind=theme: «Тема: {RU} / {EN}»
  - Если kind=rating: «Рейтинг: {value}» (при наличии — доп. подпись EN не обязательна)
- Description:
  - Брать из описания жанра/темы (RU/EN), если есть; иначе — краткий шаблонный текст без обещаний.
- Open Graph:
  - og:title = Title
  - og:description = Description

### Page Structure
Структура как у каталога:
- Верхняя шапка (collection header)
- Ниже основной блок: слева листинг, справа фильтры.

### Layout
- Container: max-width (например 1200–1320px), центрирование.
- Grid:
  - Левая колонка: список аниме (растягивается).
  - Правая колонка: фильтры (фиксированная ширина 280–340px на desktop).
- Отступы:
  - Между колонками: 24px.
  - Между секциями: 16–24px.

### Sections & Components
1. Collection Header (вверху страницы)
   - RU заголовок (обязателен, если есть RU для жанра/темы).
   - EN заголовок (показывать второй строкой/рядом меньшим кеглем).
   - Описание:
     - RU описание (если есть).
     - EN описание (если есть).
     - Если нет ни RU ни EN описания — блок описания не рендерить.
   - Доп. строка: «Найдено: N» (если в каталоге есть аналог — использовать ту же модель отображения).

2. Anime List (левая колонка)
   - Использовать тот же компонент/сетку карточек, что и в каталоге.
   - Состояния:
     - Loading (skeleton grid)
     - Empty state: «По выбранным фильтрам ничего не найдено» + кнопка «Сбросить фильтры».

3. Right Filters (правая колонка)
   - Полностью повторять состав фильтров и UI поведение каталога.
   - Инициализация:
     - При первом рендере применять предвыбранное значение в соответствующем фильтре:
       - kind=genre → выбрать жанр
       - kind=theme → выбрать тему
       - kind=rating → выбрать рейтинг
     - Остальные фильтры остаются в дефолтном состоянии.
   - Управление:
     - Смена/сброс фильтров тут же пересчитывает листинг.

### Interaction states
- При входе со страницы аниме: выбранный фильтр визуально активен.
- При смене фильтра: плавное обновление листинга (без резких скачков), допускается лёгкий fade/skeleton.
- При возврате назад: сохраняется стандартное поведение браузера (history back).

### Accessibility
- Чипы и фильтры — элементы с корректным tabindex.
- Для выбранного фильтра: aria-selected=true / role="option" где применимо.
- Заголовки RU/EN — семантика h1/h2 (h1 для RU, EN как span или h2 в зависимости от текущих пат
